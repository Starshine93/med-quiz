Я добавляю новые вопросы к медицинскому тесту (русский язык).

**Тема:** `<topicId>` — «<Название темы>»  
**PDF-источник:** `source-pdfs/<имя файла>.pdf`

1. Прочитай файл `data/questions/<topicId>.json` — это уже существующие вопросы (избегай дублей).
2. Прочитай PDF (текст + изображения слайдов при необходимости).
3. Сгенерируй **<N> новых вопросов**, которых ещё нет.
   - Только факты из этого PDF, без выдуманных деталей.
   - Дистракторы правдоподобны, но однозначно неверны по материалу слайдов.
   - Охват: определения, клинические применения, числовые данные, латинские термины, сравнения.
   - Формат каждого вопроса:
     ```json
     {
       "id": "<topicId>-<NNN>",
       "topicId": "<topicId>",
       "question": "...",
       "options": ["...", "...", "...", "..."],
       "correctIndex": 0,
       "explanation": "...",
       "difficulty": "easy|medium|hard",
       "tags": ["..."]
     }
     ```
   - ID продолжает нумерацию существующих (следующий после последнего).
   - `correctIndex` — индекс правильного ответа в массиве options (0–3).
   - Всё на русском языке. Медицинская латынь допустима там, где она педагогически важна.
4. Добавь новые вопросы в конец файла `data/questions/<topicId>.json` (APPEND, не перезаписывай).
5. Запусти валидатор: `node scripts/validate.cjs <topicId>`
6. Исправь ошибки, если есть, и сообщи реальное количество добавленных вопросов.

## После добавления вопросов

```bash
node scripts/validate.cjs            # валидация всех тем
npm run build                        # пересборка (manifest обновится автоматически)
```

Приложение читает `data/manifest.json` динамически — изменений кода не требуется.
